JERSEYSEE — RENDER + AIVEN QUICK START

Repository root requirements:
  pom.xml
  Dockerfile
  render.yaml
  src/main/java/bd/edu/seu/jerseysee/JerseySeeApplication.java

Create an Aiven MySQL service and a Render Blueprint connected to this repository.
Keep Render's Root Directory blank and Dockerfile Path set to ./Dockerfile.

IMPORTANT: In Render, create each environment variable with the KEY and VALUE in
separate fields. Do not paste "JERSEYSEE_DB_URL=" or the key name into the value.
The JERSEYSEE_DB_URL value field must contain one single-line JDBC URL only.

Required Render secret keys and their value-field formats:
  KEY: JERSEYSEE_DB_URL
  VALUE: jdbc:mysql://<AIVEN_HOST>:<AIVEN_PORT>/<DATABASE>?sslMode=REQUIRED&serverTimezone=UTC

  KEY: JERSEYSEE_DB_USERNAME
  VALUE: <AIVEN_USERNAME>

  KEY: JERSEYSEE_DB_PASSWORD
  VALUE: <AIVEN_PASSWORD>

  KEY: APP_SEED_ADMIN_EMAIL
  VALUE: <YOUR_ADMIN_EMAIL>

  KEY: APP_SEED_ADMIN_PASSWORD
  VALUE: <STRONG_UNIQUE_PASSWORD>

The Blueprint supplies these non-secret values:
  SPRING_PROFILES_ACTIVE=production
  JERSEYSEE_DEMO_CATALOG_ENABLED=true
  APP_SEED_ADMIN_ENABLED=true

APP_SEED_ADMIN_PASSWORD must contain upper- and lowercase letters, a digit,
a symbol, and 8–72 characters. The value is BCrypt-hashed before storage.
The initializer creates the administrator only when its email does not exist.
Catalog initialization is create-only in production. Render restarts never reset
sold stock, administrator price changes, product visibility, or other catalog edits.

Deployment checks:
  1. Wait for both the Docker and Render /actuator/health checks to report healthy.
  2. Open the homepage and confirm the catalog is populated.
  3. Log in with APP_SEED_ADMIN_EMAIL and APP_SEED_ADMIN_PASSWORD.
  4. Register a customer account to test cart and checkout.
  5. Upload a small product image as admin/manager and restart the service;
     the image remains available because production stores it in MySQL.

If startup says "Invalid JERSEYSEE_DB_URL", open Render > Environment and verify
that the JERSEYSEE_DB_URL value begins directly with "jdbc:mysql://" and contains
no key name, equals sign, quotes, or line break before it.

Never commit a real Aiven hostname, database password, or admin password.
